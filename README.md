# 🛍️ UTStore Store + WhatsApp Bot + Odoo Integration

Pakistan style e-commerce store — bilkul **FREE** stack pe:

| Part | Kya hai | Free host |
|---|---|---|
| 🛍️ Website (`index.html`) | 147 products, cart, COD checkout | **GitHub Pages** / **Netlify** (free) |
| 🔐 Admin Panel (`admin.html`) | Products, rates, markup, pics, orders manage | same site — `/admin.html` |
| 🤖 WhatsApp Bot (`whatsapp-bot/`) | Auto orders → WhatsApp + Gmail PDF + auto rate reply + Odoo sync | **Render** (free) + **MongoDB Atlas** (free) + **cron-job.org** (free) |

## 🚀 Deploy kaise karein?
Poori step-by-step guide: **[DEPLOY-FREE.md](DEPLOY-FREE.md)** (Roman Urdu mein — bina ek rupaya kharch kiye)

## ⚡ Quick start
1. **Website live (2 min):** [app.netlify.com/drop](https://app.netlify.com/drop) pe `utstore-website.zip` drag karo — bas!
2. **Bot live:** ye repo GitHub pe push karo → [render.com](https://render.com) se connect karo → Root Directory: `whatsapp-bot` → env vars → `/qr` pe scan
3. **Admin login:** Gmail + password (default creds DEPLOY-FREE.md mein)
