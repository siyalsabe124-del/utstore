🚀 Publish (changes sab ko live karein)

⚠️ Admin panel mein jo changes karte hain wo sirf aapke browser mein save hoti hain (preview). Sab customers ko dikhane ke liye neeche wala tareeqa follow karein — bilkul asaan hai:

📤 Step-by-step: changes live karna

  1. "Download data.js" dabayein — file aapke phone/PC mein download ho jayegi
  2. Hostinger hPanel kholein → Files → File Manager → public_html
  3. Purani data.js ko replace karein — nayi file upload kar dein
  4. Ho gaya! ✅ Ab naye products/rates sab visitors ko dikhenge
🖼️ Upload ki gayi images file ke andar hi save ho jati hain (base64) — alag se upload karne ki zaroorat nahi. Bari images se file heavy ho sakti hai, is liye chhoti/compressed pics use karein.
